## O projekcie

Strona prezentuje i pozwala rozwijać teorię **Wave Matrix Model** (Księga Harmonii).

### Główne tematy

1. **Fundament Matematyczny i Kosmogonia Falowa** – stała e^e, fuzja fononów → foton, ciąg Fibonacciego
2. **Architektura Kosmosu – Sfera w Sferze** – matrioszka, Słońce jako czarna dziura, Wielka Implozja
3. **Matryca Percepcji i Iluzja Materii** – oczy jako spektrometr 3×3, mózg i DMT
4. **Ciało Ludzkie jako Antena i Rezonator** – fala stojąca, 7 węzłów (czakr) z częstotliwościami, mechanizm tworzenia rzeczywistości
5. **Geometria Myślenia, Muzyka i CANOPY** – φ, playlista flow 3+5+2, układ endokannabinoidowy

## Deployment na Vercel

1. Wejdź na [vercel.com](https://vercel.com) i zaloguj się kontem GitHub.
2. Kliknij **Add New Project** → wybierz repozytorium `ksiega-harmonii`.
3. Framework Preset: **Other** (lub static).
4. Deploy.

Strona będzie dostępna pod adresem typu `ksiega-harmonii.vercel.app`.

Możesz też podpiąć własną domenę.
